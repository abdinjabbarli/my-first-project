# Boca Weather

Static weather app using the free, keyless [Open-Meteo](https://open-meteo.com/) API. Defaults to Boca Raton, FL; supports city search, light/dark/system themes, and is responsive.

## Run locally
Open `index.html` in a browser, or `npx serve .`

## Deploy to Netlify
No build step. Connect the repo in Netlify (publish directory `.`, from `netlify.toml`), or drag the folder onto app.netlify.com/drop.
